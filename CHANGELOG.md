# Changelog

## 0.2.0
- Expanded async Bot API method coverage and generic dynamic method fallback.
- Added concurrency limiting, configurable network retries, rate-limit exception, and safe error handling.
- Added more typed models, keyboard models, utility filters, in-memory FSM storage, and Persian text normalization.
- Improved dispatcher support for routers, edited messages, callback updates, polling offset, and graceful stop.
- Added quick-start examples and provider compatibility caveats.

## 0.1.0
- Initial asynchronous API client, polling dispatcher, basic models and filters.
